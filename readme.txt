Создай Telegram Mini App «Мани.точка» — минималистичный планировщик личного месячного бюджета и накоплений на русском языке.

Главная идея:
Приложение не ведёт реальные банковские счета и не работает с картами, наличными или переводами между кошельками. Пользователь в начале месяца вручную указывает свой доход, распределяет сумму по категориям расходов и финансовым целям, а затем вручную добавляет расходы. Приложение показывает, сколько средств осталось в целом и в каждой категории.

Позиционирование:
«Понятно, куда распределён доход, сколько уже потрачено и сколько осталось до конца месяца».

Основные сущности:
1. Месячный бюджет:
   - месяц и год;
   - доход за месяц;
   - сумма, распределённая по категориям;
   - сумма, направленная в цели;
   - нераспределённый остаток;
   - общий остаток на текущий момент.

2. Категория:
   - название;
   - emoji;
   - цвет;
   - лимит на выбранный месяц;
   - потраченная сумма;
   - остаток;
   - количество операций;
   - порядок отображения;
   - активна или архивирована.

3. Расход:
   - сумма;
   - категория;
   - дата и время;
   - комментарий, необязательно;
   - создано/обновлено;
   - soft delete.

4. Цель накопления:
   - название;
   - emoji;
   - обложка/изображение, необязательно;
   - цвет;
   - целевая сумма;
   - накопленная сумма;
   - дедлайн, необязательно;
   - статус: active / completed / archived.

Главный экран:
- приветствие: «Привет, {имя}»;
- крупный заголовок месяца: «Август 2026»;
- карточка основной цели;
- блок «Осталось в этом месяце»;
- крупная сумма остатка;
- мини-карточки:
  - «Доход»;
  - «Потрачено»;
  - «Распределено»;
- если бюджет ещё не создан, показать CTA:
  «Спланировать бюджет»
  «Распределите доход по категориям и мечте»;
- список 3–5 ближайших или проблемных категорий;
- плавающая кнопка «+» для быстрого добавления расхода.

Экран планирования бюджета:
1. Пользователь вводит «Доход в этом месяце».
2. Создаёт или выбирает категории.
3. Для каждой категории задаёт лимит.
4. При необходимости направляет часть суммы в цель.
5. В реальном времени видеть:
   - доход;
   - распределено;
   - нераспределённый остаток;
   - превышение дохода, если распределено больше доступного.

Формула:
нераспределено = доход - сумма_лимитов_категорий - сумма_отложенная_в_цели

Пользователь может оставить часть дохода нераспределённой.

Экран категорий:
Для каждой карточки покажи:
- emoji;
- название;
- «потрачено / лимит»;
- «осталось X ₽»;
- прогресс-бар;
- количество операций;
- сколько дней осталось до конца месяца;
- кнопку редактирования.

Цвета статуса:
- остаток больше 30%: спокойный зелёный;
- остаток меньше 30%: предупреждающий тёплый оттенок;
- лимит превышен: smoky rose;
- бюджет не установлен: нейтральный серо-лавандовый.

Добавление расхода:
- открыть быстрый bottom sheet;
- первым полем сделать сумму с цифровой клавиатурой;
- затем выбор категории;
- дата по умолчанию — сейчас;
- комментарий необязателен;
- сохранить через Telegram MainButton;
- после сохранения мгновенно пересчитать остатки и прогресс.

Цели:
- пользователь создаёт цель, например «Поездка в Сочи ✈️»;
- задаёт целевую сумму, дедлайн и обложку;
- при планировании бюджета может указать, сколько направить в цель в текущем месяце;
- эта сумма уменьшает доступный остаток месяца и увеличивает накопления цели;
- также пользователь может вручную пополнить цель;
- при достижении показать поздравление.

Визуальный стиль:
- mobile-first, интерфейс внутри Telegram;
- мягкие большие скругления: 28–36px;
- светлый тёплый фон #FCF6F2;
- тёмный текст #302B3B;
- основная акцентная гамма:
  #5F5449, #9B6A6C, #B09398, #CEDFD9, #EBFCFB;
- крупные суммы и заголовки;
- белые карточки с лёгкими тенями;
- основные CTA-кнопки в #B09398, белый текст;
- ненавязчивые полупрозрачные круги и органические формы в крупных цветных карточках;
- нижняя навигация:
  Главная / Статистика / Цели / Аналитика / Настройки;
- использовать Telegram theme params как fallback, но фирменную палитру сохранить приоритетной.

Осталось в месяце =
Доход месяца
− все зафиксированные расходы
− все средства, направленные в цели

Осталось в категории =
Лимит категории
− расходы этой категории за месяц

Технологии остаются удачными: React + TypeScript + Vite + Tailwind для Mini App, NestJS + PostgreSQL + Prisma для API и grammY для бота. Но благодаря отказу от настоящих кошельков модель данных, интерфейс и бизнес-правила становятся заметно проще — это хороший и понятный MVP.
